# 撰写文档

本页演示如何撰写一篇结构清晰的文档。

## 基本结构

一篇文档建议包含：

1. **一级标题（H1）**：每篇文档一个，作为页面主标题
2. **二级标题（H2）**：划分主要章节，自动出现在右侧目录
3. **三级标题（H3）**：划分小节，同样出现在右侧目录

## Markdown 语法速查

### 文本

```markdown
**加粗**  *斜体*  ~~删除线~~  `行内代码`
```

### 链接与图片

```markdown
[链接文字](https://example.com)
![图片说明](image-url.png)
```

### 代码块

````markdown
```javascript
const x = 1;
```
````

### 引用

```markdown
> 这是一段引用
```

### 表格

```markdown
| 列1 | 列2 |
|---|---|
| A | B |
```

## 排序与路由

文件名按 `标题[路由][排序]` 命名：

- `环境准备[env][0].md`：路由 `env`，排序 `0`
- `撰写文档[write][1].md`：路由 `write`，排序 `1`

完整规则见 [命名规则](#/naming)。
