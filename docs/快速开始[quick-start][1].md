# 快速开始

跟随本指南，5 分钟内让文档站点跑起来。

## 环境要求

- PHP 8.0 或更高版本（仅用于内置开发服务器或后端 API）
- 任意现代浏览器

> 如果你的服务器已经运行 Nginx / Apache 并能解析 PHP，则无需使用内置服务器，直接将项目目录放到 Web 根目录即可。

## 1. 启动开发服务器

在项目根目录执行：

```bash
php -S localhost:8000
```

浏览器访问 `http://localhost:8000/`，即可看到文档站点。

## 2. 编写第一篇文档

在 `docs` 目录下新建一个 `.md` 文件，例如：

```text
docs/
└─ 我的第一篇文档[my-first][0].md
```

文件内容：

```markdown
# Hello Fast Wiki

这是一段正文内容。
```

刷新浏览器，左侧菜单会出现「我的第一篇文档」，点击即可阅读。

## 3. 体验核心功能

| 操作 | 方式 |
|---|---|
| 搜索文档 | `Ctrl + K` 或点击顶部搜索栏 |
| 收起左侧菜单 | 点击侧边栏底部折叠按钮 |
| 收起右侧目录 | 点击目录标题栏右侧箭头 |
| 拖拽调整侧边栏宽度 | 鼠标按住侧边栏右边缘拖动 |
| 移动端菜单 | 点击右上角汉堡按钮 |
